## ⚔️ `WHAT IS THE DUNGEON MASTER AI ORACLE?`

<div align="center">

> *"The torch flickers. A robed figure turns from an ancient tome, eyes blazing with amber fire. Your adventure begins... now."*

</div>

This is a **fully AI-powered Dungeons & Dragons 5th Edition Dungeon Master** — built by George Carter of XenClipse Studios. The DM Oracle runs on **Groq's ultra-fast LLaMA 3.3 70B model**, providing real-time narrative storytelling, rule adjudication, and world-building for any D&D adventure you can imagine.

No app to download. No login required (beyond a free Groq API key). Just open the realm and play.

## 🚀 `HOW TO PLAY`

### Step 1 — Get a Free Groq API Key
Visit **[console.groq.com](https://console.groq.com)** → Sign up free → API Keys → Create Key

### Step 2 — Open the Realm
[![ENTER THE REALM](https://img.shields.io/badge/⚔️_OPEN_DUNGEON_MASTER_AI-c9a84c?style=for-the-badge&labelColor=0a0608)](https://george-mando.github.io/George-Mando/)

### Step 3 — Build Your Character
Go to the **⚔️ CHARACTER** tab → Choose your Race, Class, Background → Roll ability scores

### Step 4 — Choose a Campaign
Go to the **📜 CAMPAIGNS** tab → Select your adventure → Load it

### Step 5 — Begin Your Adventure
Go to the **🎲 DM ORACLE** tab → Enter your Groq key → Start playing!
