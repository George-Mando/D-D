🎲 ABILITY CHECKS
Roll d20 + Ability Modifier + Proficiency (if applicable). Beat the DC set by the DM Oracle.
💀 DEATH SAVES
When at 0 HP: roll d20 each turn. 10+ = success. 1-9 = failure. 3 successes = stable. 3 failures = death. 1 = 2 failures. 20 = regain 1 HP.
